## 실제 데이터 대조

독립 패키지의 raw adapter를 기존 2026-09-09 실험의 원본 복원 캐시와 비교했습니다. 데이터셋마다 녹화/task 하나를 선택했습니다.

| 데이터 | 진폭 최대 차이 | 시작점·라벨을 대조한 윈도우 수(RX 하나) | ACF 맵을 대조한 윈도우 수 | 저장 맵 최대 차이 |
|---|---:|---:|---:|---:|
| 직접 수집 S1 | 0 | 108 | 3 | 0.00048828125 |
| 직접 수집 S2 | 0 | 84 | 3 | 0.00048828125 |
| Mendeley | 0 | 14 | 3 | 0.0009765625 |

윈도우 시작점과 라벨은 정확히 일치했습니다. Mendeley는 당시 `resampled_rows`를 명시했습니다. 맵은 CPU 배치 계산과 기존 GPU 계산 사이의 float32 연산 순서 및 float16 저장 차이를 포함합니다. 전체 데이터셋의 모든 raw 파일을 이 패키지로 다시 검증했다는 뜻은 아닙니다.

## 추가 확인

- 두 ResNet18 분기(기존 2D ACF + CWT)의 CUDA forward/backward를 실행했습니다. concat 임베딩은 1024차원입니다. 전체 데이터 재학습 성능 검증은 아닙니다.
- CWT+통계 모델의 별도 CLI 학습·예측 데모에서도 raw 추론과 저장 평가 확률의 최대 차이는 약 3.6e-8이었습니다.
- wheel을 별도 가상환경에 설치하고 작업공간 밖의 임시 폴더에서 raw 생성·피처 추출·학습·예측을 실행했습니다. 실행 모듈이 배포 wheel에서 로드됨을 확인했습니다. 이 가상환경은 검증 장비의 기존 의존성 패키지를 공유했으며, 빈 OS에서 의존성을 모두 새로 설치한 검증은 아닙니다.
- 데모는 생성한 합성 신호이며 낙상 탐지 정확도 근거가 아닙니다. 이 배포 작업에서는 과거 전체 데이터 실험을 새 패키지로 다시 학습하지 않았습니다.

## 과거 실험과의 관계

피처 계산은 검증한 프로젝트 구현을 분리해 사용했습니다. 다만 이 패키지는 설정 가능한 독립 실행 버전입니다. 새 recording split, Mendeley 자동 grid 길이, float32 학습, 선택한 CNN/ResNet 초기화에 따라 과거 실험과 결과가 달라질 수 있습니다. 정확한 재현에는 동일한 raw 데이터, split, grid 길이, 모델 구성, 초기 가중치와 수치 설정이 필요합니다.
